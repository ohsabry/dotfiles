# dotfiles

macOS dev setup. `script/bootstrap` for a fresh machine, `dot` to sync after.

## Install

```sh
git clone https://github.com/ohsabry/dotfiles ~/dev/dotfiles
cd ~/dev/dotfiles
script/bootstrap
```

Then:
1. iTerm > Settings > Profiles > set "Catppuccin Mocha" as default
2. `gh auth login`
3. Edit `~/.localrc` with credentials (generated by `dot`, not in git)
4. VS Code > `Cmd+Shift+P` > "Shell Command: Install 'code' command in PATH"
5. `vim +PlugInstall`

## Structure

`*.symlink` files get linked to `~/` by bootstrap (e.g. `zsh/zshrc.symlink` -> `~/.zshrc`). All `*.zsh` files in topic folders are auto-sourced by zshrc. Machine-specific stuff goes in `~/.localrc`.

## What's in here

- zsh + starship prompt + autosuggestions + syntax highlighting
- mise for node/python/ruby versions
- vim with coc.nvim, ale, fzf, vim-go, catppuccin
- tmux with catppuccin, vim-aware pane switching
- iTerm + JetBrains Mono Nerd Font
- git with delta diffs, rebase-by-default, auto-prune
- fzf, ripgrep, eza, bat, zoxide, lazydocker, etc.
- macOS defaults (dark mode, fast key repeat, hidden files, screenshots to ~/Screenshots)
